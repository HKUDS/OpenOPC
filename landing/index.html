How it works

Three tightly-coupled loops turn a brief into a delivery

Not just an agent launcher — a coordination runtime that separates who does the work, how the work moves, and what the company remembers.

🏗️

Self-Built

Given a goal, OpenOPC derives the roles and reporting lines the task needs, then a recruiter agent fills each seat — reusing an experienced employee or onboarding a fresh hire.

⚙️

Self-Run

A manager decomposes work into a dependency DAG. Independent items run in parallel; blockers pause the sender and wake the right peer, escalating to you only when judgment is needed.

🌱

Self-Grown

Every run is distilled into per-role experience and promoted into shared playbooks that new hires inherit — so organizational knowledge compounds over time.

Quickstart

Running locally takes about a minute

OpenOPC is a local-first daemon — it drives real agent CLIs, a browser, and a persistent runtime on your machine. (That's also why this page is on Vercel and the app runs on your box.)

# Install with uv (recommended), then initialize local config
uv venv --python 3.12 && source .venv/bin/activate
uv pip install -e .
uv run python -m playwright install chromium   # for browser tools
uv run opc init

# Launch the Office UI (browser at http://localhost:8765)
uv run opc ui

# …or drive it from the CLI
uv run opc chat -p demo --mode company --company-profile corporate \
  "Plan, implement, review, and document this feature"
