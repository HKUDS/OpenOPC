How it works

One brief → a staffed company → a delivery that gets smarter

OpenOPC is a coordination runtime, not just an agent launcher. Given a goal it turns three loops: it staffs the org, runs the work, and learns from the outcome.

🏗️ Self-Builtstaff the org → ⚙️ Self-Runexecute the work → 🌱 Self-Grownlearn from the run ↺ smarter next timecompounding knowledge
1

Self-Built — staff the organization

Draw the org chart the goal demands
→
A recruiter derives roles + reporting lines; roles live in RoleConfig under a company profile.
Fill each seat — reuse a veteran or hire fresh
→
The recruiter agent picks an existing employee (carrying prior context) or a fresh template from the talent pool.
2

Self-Run — execute the work

Real work can't be fully planned. A work-item state machine drives everything: each item's phase decides three things at once.

📋

Its kanban column

Where the item stands — planning, execution, review, blocked, done.

👑

Its owner

Which role is responsible at that phase — decomposer, worker, reviewer, or final decider.

✅

Its runnability

Whether it's ready to proceed, or waiting on a dependency (AWAITING_PEER).

A manager works items across five modes; decomposition defines a dependency DAG.

executedelegatereview integraterework ⇒ ⚡ independent items run in parallel ⏳ dependents wait on prerequisites

Blockers surface mid-run. Inside the team, a blocking message pauses the sender and wakes the best-positioned role. Beyond the team's authority, the runtime escalates to the human owner — invoking your judgment exactly when it's needed.

3

Self-Grown — learn from the run

Credit and blame land where they were earned
→
User feedback resolves into per-employee evaluations; only roles that owned the relevant work items update.
Turn noisy traces into reusable lessons
→
Each role's tasks are distilled into its private experience profile (employee_evolution.json).
Recurring lessons become team playbooks
→
Promoted into shared playbooks new hires inherit from day one — so org knowledge compounds.
