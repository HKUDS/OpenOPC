CLI · interactive slash console

Drive the whole company from the terminal

opc chat opens an interactive slash console for context, sessions, runtime visibility, company work items, and org assets — no Office UI required. Source of truth: _SLASH_COMMANDS in opc/cli/app.py.

1

Two execution modes

🎯 task

One agent does the job — native, codex, claude_code, cursor, or opencode. A card is usually one task-backed chat session.

🏢 company

An org of role-agents runs a work-item DAG with manager decompose / review / escalate. --mode org is a compatibility selector for a saved org architecture.

Set it with /mode task or /mode company corporate; pick a task agent with /agent codex.

Org · talent · market

/org role|policy|strategy|saved · /talent hire|import · /market apply-preset|install · /reorg

3

Flags & safety

Cap long lists
→
--limit N (1–100 rows)
See the full untruncated text
→
--full expands compact terminal output
Confirm anything destructive
→
--yes is required for deletes / cancels
Watch token spend
→
/cost shows token & cost counters

Aliases: /p=project, /s=session, /t=task, /recovery=recover.
