The operating doctrine

The robot learns inside the task. The company learns about the robot.

The winning Physical AI company isn't the one with the best demo — it's the one with the best outer loop: the system that turns every real-world attempt into a safer, more capable next attempt. A robot can get better locally and still make the company worse globally, so local reward is never enough.

1

Two loops, never confused

⚡ Inner loop — the robot

sense → decide → move → sense. Milliseconds. VLA policy, perception, planner, control, safety supervisor. Fast enough to balance, avoid collisions, regulate force.

♻️ Outer loop — the company

capture episode → evaluate → diagnose → improve → regression-test → gate → deploy carefully → remember. Minutes to weeks. This is the loop that decides whether the robot is actually becoming more capable.

The unit of work is an episode: task request · environment · plan · actions · outcomes · independent verdict · follow-up. If you can't replay why it failed, you're not running a learning system — you're collecting expensive bloopers.

2

The non-negotiables

Maker ≠ checker
→
The policy that moved the robot doesn't declare success. An independent referee verifies with real evidence and emits a scorecard.
Safety is a gate, not a score
→
A safety failure is terminal — it blocks promotion regardless of any other score, and the change rolls back. Never "but it was faster."
A failure isn't fixed until it's hard to reintroduce
→
Every accepted fix adds a durable asset — a regression test, a sim scenario, a safety constraint, or a monitor.
Not every failure is a model update
→
Often the fix is lighting, a gripper, a fixture, a rule, slowing down, or routing to a human. "Bigger model" is a wrench, not a diagnosis.

4

Promote on evidence — the release ladder

0scripted demo→ 1teleop→ 2assisted→ 3supervised→ 4bounded autonomy→ 5generalized

Level 4 is where real economic value begins. Promote a level only when the evidence says it's safe, reliable, and economically useful in its defined operating domain — never on demo polish. Moving boxes in one aisle ≠ carrying soup in a nursing home.

The honest metric — Human Burden Ratio: human-intervention-minutes ÷ useful-operating-minutes. A robot that runs an hour but needs 20 min teleop + 15 min rescue is impressive, not autonomous. Move humans up the chain: drive → supervise → handle exceptions → design the next capability.
